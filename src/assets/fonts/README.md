# Fonts

All fonts come from npm (Fontsource), so no font files live here.

- Bricolage Grotesque Variable: headings (`font-display`, applied to h1-h3 and text-* sizes)
- Instrument Sans Variable: body (`font-sans`)
- JetBrains Mono Variable: labels and metadata (`font-mono`)
- Instrument Serif italic: rare accent (`font-accent`)
